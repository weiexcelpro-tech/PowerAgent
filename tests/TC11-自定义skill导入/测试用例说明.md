# TC11 - 自定义Skill导入

## 测试场景

来源文档：场景化操作指南 - 场景11：星辰慧记skill导入

属于「5. 自定义skill导入和使用」类别。

## 适用场景

- 已获得完整的技能文件，使用该技能完成目标任务

## 测试目的

验证智能体能否通过导入自定义skill（离线音频转写skill），使用该技能对会议音频进行识别并输出会议纪要。

## 前置条件

- 智能体已启动
- 已获取 offline-asr 技能文件包（offline-asr.zip）
- 测试用音频文件 `C:\Work606\Bash-agent\Testcase\TC11-自定义skill导入\原始数据\会议纪要.m4a` 已准备好（当前为占位文件，需替换为真实会议录音）

## 原始数据说明

| 项目 | 说明 |
|------|------|
| 技能文件 | offline-asr.zip（需从指定链接下载） |
| 音频文件 | C:\Work\202606\Bash-agent\Testcase\TC11-自定义skill导入\原始数据\会议纪要.m4a（占位文件，实际测试时需替换为真实会议录音） |
| 支持格式 | wav、mp3、m4a、pcm |

## 测试步骤

### 第一阶段：技能导入

1. 下载 offline-asr.zip 技能文件
2. 依次点击：设置 - 技能设置 - 添加工作技能 - 导入技能
3. 在导入技能弹窗中上传此技能
4. 等待审核通过后启用此技能

### 第二阶段：技能使用

1. 确保音频文件已就位（或将占位文件替换为真实会议录音）
2. 在智能体对话框中输入以下任务指令：

```
使用 @offline-asr 技能 对 C:\Work\202606\Bash-agent\Testcase\TC11-自定义skill导入\原始数据\会议纪要.m4a 进行识别，输出会议纪要
```

3. 等待智能体执行完成

## 预期结果

| 验证项 | 预期结果 |
|--------|----------|
| 技能导入 | offline-asr技能成功导入并通过审核 |
| 技能识别 | 在对话中可通过@offline-asr正确调用技能 |
| 音频转写 | 能够识别音频中的语音内容 |
| 纪要格式 | 输出为结构化的会议纪要格式 |
| 技能指定 | 必须在指令中明确@offline-asr技能 |

## 注意事项

- 需要先导入skill，待skill审核通过后启用此技能
- 在对话中，必须明确@offline-asr这个技能
- 如果输出的结果不是期望的会议纪要格式，需确认是否正确调用了@offline-asr技能，并明确要求输出会议纪要
- 本测试用例中的 `C:\Work\202606\Bash-agent\Testcase\TC11-自定义skill导入\原始数据\会议纪要.m4a` 为占位文件，实际测试时需替换为真实的会议录音文件
