# TC08 - 批量文件处理

## 测试场景

来源文档：场景化操作指南 - 场景8：批量文件处理

属于「4. 任务管理与协作」类别。

## 适用场景

- 周报合并场景
- 多个类似表格的数据合并

## 测试目的

验证智能体能否将35个部门/分公司的人力数据表合并到同一个表格中，并新增一列注明数据来源。

## 前置条件

- 智能体已启动，工作空间已设置
- 原始数据文件夹 ``C:\Work\202606\Bash-agent\Testcase\TC08-批量文件处理\原始数据\`` （含35份人力数据表）已存在

## 原始数据说明

| 项目 | 说明 |
|------|------|
| 文件数量 | 35份 |
| 文件位置 | C:\Work\202606\Bash-agent\Testcase\TC08-批量文件处理\原始数据\ |
| 文件格式 | .xlsx |
| 文件命名 | {部门/分公司名称}_人力数据.xlsx |
| 列字段 | 序号、姓名、部门、职位、学历、入职日期、联系电话、邮箱 |
| 每份记录数 | 8-30行不等 |

包含的35个部门/分公司：北京分公司、上海分公司、广州分公司、深圳分公司、杭州分公司、成都分公司、武汉分公司、南京分公司、重庆分公司、西安分公司、技术研发部、产品部、市场营销部、销售一部、销售二部、人力资源部、财务部、法务部、行政部、客服部、供应链管理部、质量管理部、安全部、战略发展部、品牌部、国际业务部、投资部、审计部、工会、后勤保障部、信息技术部、数据部、培训中心、研究院、总裁办

## 测试步骤

1. 在智能体对话框中输入以下任务指令：

```
将 C:\Work\202606\Bash-agent\Testcase\TC08-批量文件处理\原始数据\ 文件夹中的35份数据合并至一个表格中，新增一列注明数据的来源
```

3. 等待智能体执行完成

## 预期结果

| 验证项 | 预期结果 |
|--------|----------|
| 数据完整 | 35份文件的数据全部合并至一个表格 |
| 来源标注 | 新增一列标注每条数据的来源文件/部门 |
| 字段一致 | 合并后各列字段名称一致 |
| 数据不重不漏 | 合并后总行数约等于35份文件各自行数之和 |
| 无格式错乱 | 合并后数据无错行、错列 |
| 输出文件 | 生成单独的合并结果文件 |

## 注意事项

- 要明确说明要合并的数据在哪里（文件夹路径）
- 需要明确说明合并过程中的合并逻辑（新增来源列）
- 如果多个表格合并后无法判断数据来源，可在指令中注明"请注明数据的来源"
