# TC06 - 网络信息搜集与整理

## 测试场景

来源文档：场景化操作指南 - 场景6：网络信息搜集与整理

属于「3. 信息收集与调研」类别。

## 适用场景

- 需要进行某个方向的业务调研

## 测试目的

验证智能体能否对OpenClaw的发展动态进行深度调研，产出包括发展历程、关键技术、对业界影响的报告。

## 前置条件

- 智能体已启动，工作空间已设置
- 网络连接正常

## 原始数据说明

本场景无需本地原始数据文件，调研信息来源于网络搜索。

## 测试步骤

1. 在智能体对话框中输入以下任务指令：

```
@深度调研技能，对openclaw的发展动态进行调研，最终的报告以pdf格式输出，内容需要包括：发展历程、关键技术、对业界的影响
```

2. 等待智能体执行完成

## 预期结果

| 验证项 | 预期结果 |
|--------|----------|
| 调研主题 | OpenClaw的发展动态 |
| 内容-发展历程 | 包含OpenClaw从创建到当前的发展时间线 |
| 内容-关键技术 | 包含OpenClaw的核心技术架构和关键特性 |
| 内容-业界影响 | 包含OpenClaw对行业/生态的影响分析 |
| 输出格式 | 以PDF格式输出 |
| 信息来源 | 报告中标注信息来源/引用 |

## 注意事项

- 要明确说明调研的主题内容，尽可能具体
- 明确说明想要关注的重点方向（发展历程、关键技术、业界影响）
- 如果输出结果中缺少某个方向的内容，可在指令中更明确地说明要求包含的内容方向
