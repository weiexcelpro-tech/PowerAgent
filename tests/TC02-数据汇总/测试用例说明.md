# TC02 - 数据汇总

## 测试场景

来源文档：场景化操作指南 - 场景2：数据汇总

属于「1. 数据处理与分析」类别。

## 适用场景

- 需要计算平均值、总和、最大/最小值
- 需要按维度汇总（按地区、按产品、按时间）
- 需要计算同比增长、环比增长

## 测试目的

验证智能体能否基于销售明细数据按月汇总销售额和订单数，计算平均客单价，并计算同比增长率。

## 前置条件

- 智能体已启动，工作空间已设置
- 原始数据文件 `C:\Work606\Bash-agent\Testcase\TC02-数据汇总\原始数据\销售明细.xlsx` 已存在

## 原始数据说明

| 项目 | 说明 |
|------|------|
| 文件路径 | C:\Work\202606\Bash-agent\Testcase\TC02-数据汇总\原始数据\销售明细.xlsx |
| 记录数 | 3000条 |
| 列字段 | 日期、订单号、客户名称、产品类别、销售地区、销售额、成本、利润、销售员 |
| 时间范围 | 2024-2025年 |
| 特点 | 包含2024和2025两年数据，可用于同比增长计算 |

## 测试步骤

1. 在智能体对话框中输入以下任务指令：

```
基于 C:\Work\202606\Bash-agent\Testcase\TC02-数据汇总\原始数据\销售明细.xlsx ，按月汇总销售额和订单数，计算每月平均客单价，与去年同期相比计算同比增长率，输出为"月度销售汇总.xlsx"
```

2. 等待智能体执行完成

## 预期结果

| 验证项 | 预期结果 |
|--------|----------|
| 汇总维度 | 按月份进行分组汇总 |
| 销售额 | 每月销售额合计正确 |
| 订单数 | 每月订单数统计正确 |
| 平均客单价 | 平均客单价 = 月销售额 / 月订单数 |
| 同比增长率 | 2025年各月与2024年同月相比的增长率计算正确 |
| 公式使用 | 计算字段使用Excel公式而非硬编码值 |
| 输出文件 | 生成"月度销售汇总.xlsx"文件 |

## 注意事项

- 明确汇总维度（"按月份"）
- 明确计算指标（"销售额"、"订单数"、"客单价"、"同比增长率"）
- 建议让智能体先预览数据结构，再执行计算
- 检查原始数据是否有重复记录，如有需先去重再汇总
