# TC10 - 创建网页小应用

## 测试场景

来源文档：场景化操作指南 - 场景10：创建网页小应用

属于「4. 任务管理与协作」类别。

## 适用场景

- 与客户初次沟通时，结合客户需求，快速产出原型
- 用户研究场景、产品讨论阶段，需要快速论证业务逻辑

## 测试目的

验证智能体能否快速生成一个高质量数据集管理系统的网页原型，包含数据导入、数据概览、数据标注、数据评测及 数据被访问量5大模块。

## 前置条件

- 智能体已启动，工作空间已设置
- 创建网页小应用技能可用

## 原始数据说明

本场景无需本地原始数据文件，原型基于指令描述生成。

## 测试步骤

1. 在智能体对话框中输入以下任务指令：

```
生成一个高质量数据集管理系统的网页，需要包括：数据导入、数据概览、数据标注、数据评测四大模块
```

2. 等待智能体执行完成

3. 在智能体对话框中继续输入以下任务指令：

```
在刚才高质量数据集管理系统的网页上添加 数据被访问量模块
```

## 预期结果

| 验证项 | 预期结果 |
|--------|----------|
| 模块完整 | 包含5大模块：数据导入、数据概览、数据标注、数据评测， 数据被访问量 |
| 页面可访问 | 生成的网页可在浏览器中正常打开和交互 |
| 界面美观 | 界面布局合理，具有一定的视觉质量 |
| 功能展示 | 各模块具备基本交互能力（按钮点击、页面跳转等） |

## 注意事项

- 需要明确说明要做的原型是什么、主要功能点有哪些
- 若有特定的交互动作，需在输入中说明（如：通过拖拽、点击的方式）
- 如果输出的原型中缺少功能点，可在输入中注明具体包括哪些功能、功能的层级结构
