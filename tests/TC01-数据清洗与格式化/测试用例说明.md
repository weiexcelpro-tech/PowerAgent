# TC01 - 数据清洗与格式化

## 测试场景

来源文档：场景化操作指南 - 场景1：数据清洗与格式化

属于「1. 数据处理与分析」类别。

## 适用场景

- 原始数据格式混乱（合并单元格、空行、错位）
- 需要统一格式（日期格式、数字格式、文本格式）
- 需要删除重复数据、填充空值

## 测试目的

验证智能体能否对格式混乱的Excel数据进行清洗，包括：删除空行、按指定字段去重、统一日期格式、统一数字精度。

## 前置条件

- 智能体已启动，工作空间已设置
- 原始数据文件 `C:\Work\202606\Bash-agent\Testcase\TC01-数据清洗与格式化\原始数据\销售数据.xlsx` 已存在

## 原始数据说明

| 项目   | 说明                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------ |
| 文件路径 | C:\Work\202606\Bash-agent\Testcase\TC01-数据清洗与格式化\原始数据\销售数据.xlsx                                  |
| 记录数  | 约500条                                                                                            |
| 列字段  | 订单号、日期、客户名称、产品、数量、单价、销售额、地区、销售员                                                                  |
| 已知问题 | 1) 日期格式不统一（YYYY/MM/DD、YYYY-MM-DD、YYYY年MM月DD日、M/D/YYYY混合）；2) 存在约10行空行；3) 存在约15条重复数据；4) 销售额小数位数不统一 |

## 测试步骤

1. 在智能体对话框中输入以下任务指令：

```
对 C:\Work\202606\Bash-agent\PowerAgent-v0.3\tests\TC01-数据清洗与格式化\原始数据\销售数据.xlsx 进行清洗：删除空行，按"订单号"去重，统一日期格式为YYYY-MM-DD，销售额保留2位小数，输出为"销售数据_清洗版.xlsx"
```

2. 等待智能体执行完成
3. 然后再输入指令： 分析数据生成饼图
4. 等待智能体执行完成

## 预期结果

| 验证项   | 预期结果                                   |
| ----- | -------------------------------------- |
| 空行删除  | 清洗后文件中无空行                              |
| 数据去重  | 按"订单号"字段去重，无重复订单号                      |
| 日期格式  | 所有日期统一为 YYYY-MM-DD 格式                  |
| 销售额精度 | 所有销售额保留2位小数                            |
